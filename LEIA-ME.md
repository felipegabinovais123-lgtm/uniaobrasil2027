# União Brasil Transportes — Redesign visual

Projeto baseado nos três arquivos originais enviados pelo usuário. Preserva a tela inicial, a área do destinatário, o dashboard, entregas, rastreamento, frota, segurança e alertas.

## Abrir
Abra `index.html` no Chrome ou Edge. Para mapas, use conexão à internet. Para publicar, envie os quatro arquivos HTML/CSS/JS da pasta para a raiz do repositório GitHub Pages.

## Limitações
Dados de entregas, drones, temperaturas e trajetos são demonstrativos. O OpenStreetMap fornece a cartografia real; as rotas não representam rotas aéreas homologadas. A aplicação não possui autenticação, banco de dados, GPS em tempo real nem integração XGlobal. Se o servidor de mapas estiver bloqueado, aparece aviso com link externo.
